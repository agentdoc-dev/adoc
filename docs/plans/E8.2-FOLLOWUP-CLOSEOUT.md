**Probe P2: real guard.** Run the merged `observe_protection` function itself, extracted from Action `main`, under each App token. It runs with the script's own `set -uo pipefail`: without it, a failing paginated `gh` in the rules pipeline is masked and the function accepts (F3).

The function spans `deliver.sh:104-151` at `83a1da8`. The agent re-derives the span on merged Action `main` (`grep -n '^observe_protection()'` and its closing brace), extracts by that range, and aborts unless `bash -n` accepts the extract and it is byte-identical to `sed -n '104,151p'` of `scripts/deliver.sh` at `83a1da8` (the reviewed body). Both checks are independent of how the span was derived. On a difference, the agent stops and re-derives the §4 readout against the new body before probing. The function depends only on `gh`, `jq`, `GITHUB_REPOSITORY` and `HEAD_REF`: it calls no `deliver.sh` helper and reads no other script-level variable.
```sh
# Illustrative (agent-local)
sed -n '104,151p' scripts/deliver.sh > "$S/observe.sh"
GH_TOKEN="$inst" GITHUB_REPOSITORY=storywork-io/agentdoc-e82f-probe HEAD_REF=feat/x \
  bash -c 'set -uo pipefail; . "$1"; observe_protection' _ "$S/observe.sh"
```

It is run for `HEAD_REF` = `feat/x`, `feat/z`, `feat/unrelated-y`, `feat/orgbypass-w` and `main`.

Readout: the function returns 0 and prints the protection profile JSON (`{branch, classic, rules, rulesets}`) on stdout when it accepts. It returns non-zero with empty stdout on every refusal, so P2 cannot tell *why* it refused: the "refused (bypass)" cells are the expected mechanism, and attribution comes from P1's ruleset reads; both call sites (`deliver.sh:380`, `:683`) map that to `refuse_protection protection_unknown`, i.e. fallback `delivery_check_failed`. P2 records exit status, stdout and stderr per run. *accepted* means exit 0 with a JSON object whose `branch` equals `HEAD_REF`; *refused* means non-zero exit with empty stdout. Anything else (exit 0 with empty or non-JSON output, or non-zero exit with stdout) is a probe failure, not a verdict.
