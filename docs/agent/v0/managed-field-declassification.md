# Governed field declassification

`adoc.managed_field_declassification.v0` is an immutable detail linked to the ordinal and digest of one existing bare managed declassification state event. Its [schema](schema/adoc.managed_field_declassification.v0.schema.json) is available through MCP. The core builder and validator establish shape; they grant no authority.

Native admission requires a current authenticated human with `knowledge.declassify` and an exact object-scope allowed decision. The record binds workspace/canonical/version/content, the sealed field-provenance manifest digest, exact selected `/body` or `/fields/<one JSON Pointer token>` selectors, their contributing native assertion UUIDs, prior/new classifications, principal/session/decision/policy, rationale and effective date. Restricted evidence remains hidden; its assertion snapshots and content are never lowered or rewritten. Missing or conflicting provenance fails closed.

There are 1–100 distinct fields, each with 1–100 distinct assertions. Canonical core serialization sorts selectors and assertion IDs. UUIDs and SHA256 digests use the existing lowercase forms. Event ordinal is a zero-based safe integer. Policy version is exact nonblank text, not necessarily a UUID. Rationale is nonblank and at most 4096 Unicode scalars. Effective date is Gregorian `YYYY-MM-DD`. Duplicate/unknown members, positional arrays, null required values, equal/higher classes and a false evidence-withholding posture are refused.

Native admission serializes a strictly descending per-selector chain with nondecreasing effective dates. The first prior is the strictest original floor; a successor's prior equals the latest admitted target, including pending approvals. Latest currently effective event applies under the native UTC clock. Bare marker corrections do not change these details. Exact request replay retains the original event and detail. New versions or missing current source access invalidate the relevant read; a historical approval never grants source ACL access.

The private managed projection carries only an optional reference with `state_event_ordinal`, `state_event_digest`, `detail_digest`, and `prior_classification`. Its row classification is the currently effective class. Without this reference, the original object/authored/contributor maxima remain in force. A null classification never lowers. Core validates strict descent but does not compare a successor's prior with the unchanged original object floor: native admission and exact final projection checks prove that chain. A well-shaped reference is not self-authenticating; the trusted Cloud adapter obtains and rechecks it natively before releasing data.

When an original object is unreadable but selected approved scalars are readable, retrieval returns only those scalars plus identity/hash binding. It emits `source: {}`, empty required body if unselected, and empty relations. Dedicated status, lifecycle, references, evidence, source locations and unselected generic fields remain hidden; no classification or location is fabricated. Ordinary authorized siblings keep their original sensitivity. Existence exclusion still wins. Canonical receipt/content bytes and hashes remain unchanged.

Cloud requires `managed-retrieve --require-field-declassification`; older binaries refuse that flag. Ordinary local retrieval/rendering has no declassification authority input. Patch proposer labels are descriptive, so target-aware patch validation refuses authored classification lowering for agent, unattributed, and human-labelled patches alike. A proposal can suggest escalation in its reason without modifying visibility; only native governed admission grants the new lowering authority.
